Which one should I choose? Legacy: after login we redirect your user to your redirect URL with the proxy_auth_token in the URL. Nothing else to set up, but the token can end up in browser history and server logs. Code: after login we redirect with a short-lived, single-use code instead. Your server then exchanges it for the proxy_auth_token by calling POST /c/exchange with the code and one of your client secrets. Tokens never appear in the URL, so we recommend this option. Before you switch to Code: create a client secret below and update your server to do the exchange. Until then, logins that arrive with only a code can't be completed.
